# pedrosantos.dev — versão 2027 ("Tinta & papel")

Branch nova `2027` criada a partir de `new-site` (levando junto as correções de datas não-commitadas), com commits progressivos.

## Conceito

Site editorial claro e acolhedor — tipografia serif grande, "papel quente", tinta azul — onde a assinatura é o **Log de aprendizados co-escritos com AI** (entradas curtas com o prompt incluído) e um **chat real "pergunta ao meu site"**. Diferencia-se de tudo que já tentaste: não é dark minimal (site atual), nem flashoso (v3), nem sidebar/coral (redesign), nem editorial puro (v2).

Referências: emilkowal.ski, maggieappleton.com, rauno.me, joshwcomeau.com.

## Design system

- **Fontes** (next/font): `Instrument Serif` (display/headlines gigantes), `Newsreader` (leitura longa), `JetBrains Mono` (labels, log, código).
- **Tokens** (CSS vars + Tailwind **v4** `@theme`): papel quente `~#FAF6F0` / tinta `~#1C1917`; accent **azul-tinta** (herança do teu azul atual, versão editorial); violeta só para o selo ✦ "co-escrito com AI". Dark = "modo noturno" coeso (preto quente), com **toggle real** (`next-themes`, respeita sistema) — mata o hack de dark forçado.
- Hairlines 1px, radius pequeno, whitespace generoso, `clamp()` para display. Motion discreto: view transitions (mantém), fade-up, springs leves; `prefers-reduced-motion` respeitado em tudo.
- Migrations: **Tailwind 3 → 4** (tokens vão pro CSS, `tailwindcss-animate` → `tw-animate-css`), **bun** oficial (remove `package-lock.json`, ajusta `packageManager`), remove deps mortas (`framer-motion`, UI shadcn não usada — o kit é substituído por componentes editoriais próprios; RHF+zod ficam).

## Chat AI (`/api/ask`)

- POST com streaming (text stream) → provider-agnostic: `AI_API_KEY` + `AI_BASE_URL` (default Groq) + `AI_MODEL` (ex.: `llama-3.3-70b-versatile`), system prompt montado server-side a partir de `profile.ts`, `projects.ts`, `now.ts` e títulos/resumos do log (conteúdo pequeno, cabe inline).
- Rate limit simples por IP (ex. 10/min), cap de tokens e de tamanho de input.
- **Fallback**: sem chave → responde `{mode:"offline"}` e o cliente usa o gerador de Q&A roteado (hoje) — site nunca quebra. `.env.example` documentado; disclosure "AI pode errar, base: meu conteúdo".
